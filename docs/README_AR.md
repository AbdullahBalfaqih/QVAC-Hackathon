# أثر الحضور

أداة محلية لمراجعة اختلاف معلومات الحضور. يستخدم التطبيق QVAC ونموذج Qwen محليًا لاقتراح الأرقام واقتباساتها من النص، ثم يراجع الشخص المصدر ويصنّف كل اقتراح. لا يثبت اختلاف الأرقام صحة السجل أو استحقاق الأجور، ولا يرسل التطبيق مطالبة تلقائيًا.

## البدء

اختُبر Linux x64 فقط. Windows مسار مستهدف لم يُختبر، وتذكر متطلبات QVAC ضرورة Vulkan 1.4 أو أحدث على Windows حتى عند استخدام المعالج. يلزم Node.js 22.17 أو أحدث، ويفضّل توفير 4 GB ذاكرة و6 GB مساحة حرة. يحتاج تثبيت التبعيات وتنزيل النموذج إلى الإنترنت مرة واحدة؛ حجم النموذج الافتراضي نحو 986 MB.

```bash
node scripts/install-locked.mjs
node scripts/download-model.mjs
node server.mjs
```

افتح `http://127.0.0.1:4174` على الجهاز نفسه وانتظر `QVAC ready`. بعد الإعداد يعمل الاستدلال محليًا دون إنترنت؛ فتح روابط المقالات الخارجية يحتاج اتصالًا. تعليمات Windows وCSV وإعادة الاختبار في [دليل الإعداد](SETUP.md).

## دليل التشغيل

[الفيديو بالتعليق الصوتي](../evidence/Athar_Narrated_Demo.mp4) يحتوي مقدمة وشرحًا صوتيًا مولّدًا بالذكاء الاصطناعي، ثم تسجيل متصفح آلي حقيقي دون قص أو تسريع الاستدلال. عُزل المتصفح والخادم وعامل QVAC في مساحة شبكة Linux واحدة دون مسارات IPv4، وأعاد اختبار الاتصال `ENETUNREACH` قبل الاستدلال وبعده. هذا يثبت عزل **بيئة التطبيق**، وليس إطفاء Wi-Fi للجهاز المضيف. [دليل الاختبار](../evidence/offline-proof.json).

استخرج النموذج 9 و4 من مقطع صحفي واحد خلال 36.910 ثانية في هذا الاختبار؛ لا تثبت العينة دقة عامة أو صحة الكشوف الأصلية. الحالات أمثلة تاريخية من تقارير منشورة، وصور الأشخاص مولّدة ولا تصوّر أصحاب الحالات. انظر [المصادر](SOURCES.md).

البيانات المحلية والنسخ المصدرة غير مشفرة؛ لا تدخل معلومات حساسة على جهاز غير موثوق أو في معاينة بعيدة. راجع [الخصوصية والأمان](../SECURITY.md). الاسترداد الفعلي للأجور والنشر الميداني وWindows غير مختبرة.
